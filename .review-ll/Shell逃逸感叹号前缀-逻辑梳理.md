# Shell 逃逸（! / ！）— 逻辑梳理

## 分流

```text
用户输入
  ├─ 以 ! 或 ！ 开头 → strip 前缀 → 直接 run_shell（无确认）
  ├─ /help /reload /quit → 内建
  └─ 其它 → 中文意图匹配（查询只展示 / Agent 可执行）
```

## 为何两个前缀

- `!`：英文键盘  
- `！`：中文输入法下误/常打的全角感叹号，避免「看起来像逃逸却进了意图匹配」

## 与 agent> 手输英文的区别

| 输入 | 行为 |
|------|------|
| `pwd`（agent>，无前缀） | shell，**仍确认**（风险随当前意图） |
| `查看目录` | 意图匹配 |
| `!pwd` / `！ls` | 任意提示符下强制 shell，**不确认** |
| `!查看 /tmp/中文` | 强制 shell（可含中文路径），不确认 |

## 限制

子进程不共享 cwd：`!cd /tmp` 后下一条 `!pwd` 仍在启动目录。
