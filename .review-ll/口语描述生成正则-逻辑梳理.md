# 口语描述生成正则 - 逻辑梳理

## 目标

把「5个汉字 / 5个数字 / 必须包含 / 不能包含」等约束，映射成可复制的正则字符串（python 打印），而不是开放式 NL→任意正则生成。

## 映射

| 约束 | 典型模式 |
|------|----------|
| 恰好 n 位数字 | `^[0-9]{n}$` / `^\d{n}$` |
| 恰好 n 个汉字 | `^[\u4e00-\u9fff]{n}$` / `^\p{Han}{n}$` |
| 必须含 t | `.*t.*` 或 `^(?=.*t).*$` |
| 不能含 t | `^(?:(?!t).)*$`；筛行用 `grep -vF` |

组合（长度 + 包含）写在 tips，由用户手拼，例如 `^(?=.*xx)[0-9]{5}$`。

## 与 text.* 分工

- `text.*`：改文件内容（sed）
- `regex.*`：给出/试跑模式；`regex.grep.test` 才碰文件只读搜索

## 实现要点

- 用 `python3 -c` 拼 `{n}` 量词，避免 JSON/`fill_template` 花括号转义陷阱
- `n` 不进 `_QUOTE_KEYS`，便于 `int({n})`
- 别字「不能包换」做关键词，兼容用户笔误
