# 选命令预填输入 — 逻辑梳理

```
agent> 数字
  ├─ single → cmd> [readline 预填 runnable.cmd] → strip
  │            空 → 取消
  │            仍含 {} → 提示改全
  │            否则 → confirm → 执行
  └─ sequence → step> 每步 [预填 current]
                 回车/与预填相同/y → 本条确认执行
                 其它文本 → 改参后确认
                 s/n/all → 需清空预填后再输入
```

`read_with_prefill`：仅当 `input_fn is input` 且 TTY 时 `readline.insert_text`（**不要** `redisplay`，否则 prompt 重复）；非 TTY 的真实 input 打印「默认命令」；注入的 input_fn 不预填。
