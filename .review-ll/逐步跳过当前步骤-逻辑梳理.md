# 逐步跳过当前步骤 — 逻辑梳理

## step> 分流（跳过相关）

```text
step> 输入
  ├─ s / skip / 跳过 / 略过
  │     → 审计 skipped=true（不执行）
  │     → 打印「已跳过第 i/n 步」
  │     → idx += 1
  ├─ y / 手改 → 确认后执行；失败且 stop_on_error 则停在本步（可再跳过）
  ├─ all → 确认后连跑剩余
  └─ n / 空行 → 退出逐步模式回 agent>
```

## 与确认的关系

跳过**不**走 `confirm_execute`；未执行、未确认。失败确认后的「否」仍停在本步，需再输入跳过才会前进。

## 审计字段

`mode=step`，`skipped=true`，`confirmed=false`，`exit_code=null`，`step_index` 为 1-based。
