# 评审 P0/P1 落地 — 逻辑梳理

## Shell 逃逸决策树

```text
输入 !cmd / ！cmd
  → 纯 cd？ → 更新 session cwd，返回
  → 查询模式？ → 一律 confirm
  → Agent 且高危？ → confirm
  → 否则直接 run_shell(cwd=session)
```

## 手输风险

```text
agent> 无前缀英文
  → estimate_manual_risk(cmd)  // 不读当前意图 risk
  → confirm → run_shell
```

## 会话 cwd

`get_cwd()` 默认进程 cwd；`!cd` / `try_handle_cd` 更新后，后续执行带 `cwd=`。
