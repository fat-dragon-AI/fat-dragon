# 逻辑梳理：硬件与系统配置规则

| 项 | 内容 |
|----|------|
| 日期 | 2026-08-10 |

## 意图区分

| 用户说法 | 命中 |
|----------|------|
| cpu 占用高 | `sys.cpu.usage`（利用率） |
| cpu 型号/几核 | `sys.cpu.model` |
| 内存还剩多少 | `sys.mem.free` |
| 内存型号/几条 | `sys.mem.model` |
| 系统配置/概况 | `sys.config.summary` |
| 硬件配置/整机 | `sys.hw.overview` |

## 权限说明

- 型号类（dmidecode/lshw）多需 sudo；规则已写在 tips，Agent 执行时用户自行确认。
- 无 sudo 时仍可用 `lscpu` / `free` / `lsblk` / `df` 看容量与规格摘要。
