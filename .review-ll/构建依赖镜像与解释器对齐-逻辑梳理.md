# 构建依赖安装与解释器对齐 — 逻辑梳理

## 问题

`build_release.sh` 使用 `command -v python3` → 常为 `/usr/bin/python3`。  
包若装在 miniconda，会出现「装过了但构建报未安装 PyInstaller」。

## 选择顺序（三处统一）

```text
LCH_PYTHON（显式覆盖）
  → $ROOT/.venv/bin/python
  → $HOME/.local/miniconda3/bin/python3
  → $HOME/miniconda3/bin/python3
  → PATH 中的 python3
```

适用：`bin/lch`、`scripts/install_build_deps.sh`、`scripts/build_release.sh`。

## 安装数据流

```text
requirements-build.txt（注释含镜像 URL）
        │
        ▼
install_build_deps.sh
  pick_python → python -m pip install -r ...
    -i 清华 simple
    --extra-index-url PyPI simple
        │
        ▼
build_release.sh（同一 PY）
  import PyInstaller → pyinstaller 打包
```

## 约束

- 不对无 pip 的系统 Python 静默装包  
- 下载须国内源优先、国外兜底，执行前确认
