# 逻辑梳理：短关键词与整句加成

## 短查询路径

```text
输入 "path"
  → 命中 env.path.view 关键词 path（词边界）
  → 整句等于 path → +8
  → exact，展示查看 PATH 命令
```

## 为何裸 path 不挂 write

「加入path」等长词留给 `env.path.write`；裸 `path` 只挂 `env.path.view`，避免短输入直接落到改 bashrc。

## ASCII 短词边界

`(?<![a-z0-9_])kw(?![a-z0-9_])`：允许 `java版本`（后接中文），拒绝 `javascript`。
