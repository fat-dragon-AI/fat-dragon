# 评审 P3 落地 — 逻辑梳理

```
口语 query
  → jieba tokens
  → score_rule_jieba
       ├─ 长 token：与 kw 相等 / 互相包含
       ├─ 短 token(≤2)：仅完全相等
       └─ 原文 kw 辅分：短中文 ×0.25，其它 ×0.5
  → Top-K / exact|weak
```

```
多步排查意图
  → candidates[kind=sequence].steps
  → Agent 逐步确认执行（非「选一行互替」）
```

```
build_release.sh
  → 复制 rules.json + rules.d + templates
  → SHA256(路径+内容)[:16] → VERSION / RULES_STAMP.json
  → tar.gz
```

核对：解压包后对比 `rules_sha256_16` 与当前仓库同算法结果，可判断是否旧包。
