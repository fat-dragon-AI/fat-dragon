# 国内常用镜像地址 - 逻辑梳理

## 定位

运维口语 → **国内下载/构建源** 的地址与配置命令，不是 Docker 本地 `images` 列表。

## 易混词

| 说法 | 意图 |
|------|------|
| 国内镜像 / npm镜像 / maven镜像 | `mirror.*` |
| 有哪些镜像 / 镜像列表 / docker镜像 | `docker.images`（本地） |
| docker镜像加速 | `mirror.docker`（daemon 加速） |

## 匹配注意

`go镜像` 曾是 `cargo镜像` 的子串误命中；两处修复：

1. `matcher._hit`：英文前缀+中文关键词加 `(?<![a-z0-9_])` 边界  
2. `expand_query_with_synonyms`：组触发改用 `_hit`，避免同义词把 go 组灌进 cargo 查询

- Java：`maven.aliyun.com/repository/public`，优先 `~/.m2/settings.xml`
- Python：清华 simple + 官方 extra-index 兜底
- Docker：公共 mirror 易失效，tips 提示可换云厂商个人加速器
- apt：只给地址与查看现状；真正 `apt-get update` 仍走 `pkg.apt.update`
