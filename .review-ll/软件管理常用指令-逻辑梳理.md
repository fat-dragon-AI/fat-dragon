# 软件管理常用指令 — 逻辑梳理

```
口语（软件列表 / 卸载 nginx / 命令在哪 / 软件本体位置 …）
  → matcher → pkg.list | pkg.remove | pkg.which | pkg.files | pkg.info
  → extract: pkg（装个 / 卸载 / which / nginx装在哪）
  → render：{pkg_list}/{pkg_remove}/{pkg_files} 等按发行版替换
```

| 意图 | 典型说法 | 主命令 | 含义 |
|------|----------|--------|------|
| list | 软件列表 / 已装软件 | `{pkg_list}` | 已装包清单 |
| remove | 卸载软件 / 卸载 nginx | `{pkg_remove} {pkg}` | 卸包（high） |
| which | 命令在哪 / which nginx | `which` / `readlink -f` | PATH 上的可执行文件 |
| files | 软件本体位置 / nginx装在哪 | `{pkg_owns}` → `{pkg_files}` | 包登记的安装文件（本体） |
| info | 软件包信息 | `{pkg_info} {pkg}` | 版本与描述 |
| install | 装个 htop | `{pkg_install} {pkg}` | 原有安装 |

**位置 vs 本体**：`which` 只回答「命令在 PATH 的哪」；本体是 rpm/dpkg 登记的文件树（配置、库、二进制），命令名和包名可能不同，故 files 先 `pkg_owns "$(which …)"` 再列文件。

适配：Debian `dpkg -l/-L/-S/-s` + `apt-get remove/purge`；RHEL `rpm -qa/-ql/-qf/-qi` + `yum remove`。
