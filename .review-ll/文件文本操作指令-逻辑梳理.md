# 文件文本操作指令 - 逻辑梳理

## 定位

相对 `file.find.content`（只读 grep）与 `echo.write.file`（整文件重定向），本分片覆盖**文件内局部改写**。

## 意图分工

| 意图 | 动作 | 风险策略 |
|------|------|----------|
| `text.replace` | `{text}`→`{value}` | 先 grep 预览，可选 `.bak` |
| `text.delete.substr` | 子串置空 | 同上 |
| `text.delete.line` | 含 `{text}` 的整行删掉 | 同上 |
| `text.delete.blank` | 删 `^$` | 先统计空行数 |
| `text.append.line` | `printf >>` | tail 确认 |
| `text.insert.after` | GNU `sed a\\` | 先预览匹配行 |

## 模板注意

- 替换用 `s|{text}|{value}|g`，避免路径里的 `/` 与分隔符冲突；串内含 `|` 需手改。
- `fill_template` 会对 `text`/`value`/`path` 自动加壳引号，故模板中**不要**再给占位外包一层 `'…'`。
- 关键词避开裸「删掉」「删除」，防止抢 `pkg.remove` / `docker.rm`。

## 抽取

在 `extract.py` 于 echo 文本抽取之前增加替换/删除/追加模式；`text`/`value`/`path` 已在 session 白名单。
