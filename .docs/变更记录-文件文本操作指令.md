# 变更记录：文件文本操作指令

日期：2026-08-24

## 功能

新增分片 `resources/rules.d/34-text.json`（已纳入 `rules.json` include）：

| intent_id | 说明 |
|-----------|------|
| `text.replace` | 预览 → `sed` 原地替换（可 `.bak`） |
| `text.delete.substr` | 删除文件中某段子串 |
| `text.delete.line` | 删除包含某文本的整行 |
| `text.delete.blank` | 删除空行 |
| `text.append.line` | 文件末尾追加一行 |
| `text.insert.after` | 在匹配行后插入一行 |

占位：`{text}` 旧串/删串/追加内容，`{value}` 新串/插入行，`{path}` 目标文件。

## 代码

- `lch/extract.py`：口语抽取「把 A 换成 B / 替换 A 为 B / 删掉文本 / 删除包含…的行 / 追加」
- `resources/dict/synonyms.json`：同义词组
- 语料、matcher/extract 回归、README 示例与占位说明
