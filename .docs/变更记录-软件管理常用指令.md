# 变更记录：软件管理常用指令

日期：2026-08-13

## 功能

在 `resources/rules.d/40-svc-pkg.json` 扩展 `pkg.*`（原仅有 `pkg.install`）：

| intent_id | 说明 |
|-----------|------|
| `pkg.list` | 已装软件列表（`rpm -qa` / `dpkg -l`，可 grep 包名） |
| `pkg.remove` | 卸载（`{pkg_remove}` / `{pkg_purge}`，high） |
| `pkg.which` | 命令位置：`which` / `type` / `whereis` / 真实路径 |
| `pkg.files` | 软件本体：所属包 + 包内文件列表（`rpm -ql` / `dpkg -L`） |
| `pkg.info` | 包详情（版本/描述） |

`system_adapt.json` 为 debian / rhel 增加：`pkg_remove`、`pkg_purge`、`pkg_list`、`pkg_files`、`pkg_owns`、`pkg_info`。

与 `java.home.env` 分工：泛化命令/包路径走 `pkg.which` / `pkg.files`；Java 安装根仍走 `java.home.env`。

## 代码

- `extract.py`：卸载 / which / 「装在哪」提取 `{pkg}`
- `render.py`：映射上述适配占位符
- 语料与核心 Top-1 补充软件列表、卸载软件

无。
