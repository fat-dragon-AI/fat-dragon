# 变更记录：国内常用镜像地址

日期：2026-08-25

## 功能

新增 `resources/rules.d/38-mirrors.json`：

| 口语 | intent | 内容 |
|------|--------|------|
| 国内镜像 | `mirror.overview` | 常用源一览 |
| npm镜像 / 淘宝镜像 | `mirror.npm` | npmmirror.com（npm/pnpm/yarn） |
| maven镜像 | `mirror.maven` | 阿里云 Maven + settings 片段 |
| gradle镜像 | `mirror.gradle` | 阿里云仓库 URL |
| pip镜像 | `mirror.pip` | 清华 / 阿里 + pip config |
| docker镜像加速 | `mirror.docker` | daemon.json registry-mirrors |
| go镜像 | `mirror.go` | goproxy.cn |
| apt换源 | `mirror.apt` | 阿里/清华/中科大地址与现状查看 |
| composer镜像 | `mirror.composer` | 阿里云 Composer |
| cargo镜像 | `mirror.cargo` | USTC sparse 示例 |

与「docker 镜像列表」区分：拉取加速用「docker镜像加速」。

`matcher`：英文+中文关键词（如 `go镜像`）增加前缀边界，避免被 `cargo镜像` 吞掉。
