# 变更记录：口语描述生成正则

日期：2026-08-24

## 功能

新增 `resources/rules.d/37-regex.json`：

| 口语 | intent | 产出 |
|------|--------|------|
| 5个数字 / n个数字 | `regex.len.digit` | `^[0-9]{n}$` 等 |
| 5个汉字 / n个汉字 | `regex.len.han` | `[\\u4e00-\\u9fff]{n}` / `\\p{Han}{n}` |
| n个字符 | `regex.len.any` | `^.{n}$` |
| 必须包含 xx | `regex.must.contain` | `.*xx.*` / 前窥 |
| 不能包含 / 不能包换 xx | `regex.must.not.contain` | 负向前窥 / `grep -vF` |
| 正则语法 | `regex.cheat` | 元字符速查 |
| 正则搜文件 | `regex.grep.test` | `grep -E/-P` |

`{n}` 由「数字+个+汉字/数字/字符」抽出；`{text}` 为包含/排除串。
