## 背景

`sequence` 进入 `step>` 后需要能跳过当前步（例如检查步已手动做过、或失败后不想重试）。原先已支持 `s`/`skip`，但无明确反馈，且不认中文「跳过」，易被当成手输命令。

## 功能变更

- 跳过入口：`s` / `skip` / `跳过` / `略过`
- 跳过后打印：`已跳过第 i/n 步: <命令>`，并写审计 `skipped=true`
- 失败停步提示改为：可手改重试、`s/跳过` 进下一步，或 `n` 退出
- `/help`、进入提示与 Agent 帮助同步写明跳过

## 用法

```text
step> 当前 1/3: ls -lah /opt/app
step> s
已跳过第 1/3 步: ls -lah /opt/app
step> 当前 2/3: chmod 755 /opt/app
step> 跳过
已跳过第 2/3 步: chmod 755 /opt/app
```
