## 功能

选中可执行命令后，下一行输入框**自动带入该命令**（readline 预填，可改参再回车）。

| 场景 | 行为 |
|------|------|
| `agent>` 选 single 编号 | 进入 `cmd>`，已填该条命令；回车后二次确认；空行取消 |
| 仍含 `{占位符}` | 提示改全，不执行 |
| `step>` 逐步 | 每步输入行预填当前命令；回车=执行本条；改字后回车=改参；`s`/`n` 需先清空预填（如 Ctrl+U） |

## 显示修复（2026-08-20）

预填 hook 内勿调用 `readline.redisplay()`，否则会出现 `cmd> xxxcmd> xxx` 重复绘制；仅 `insert_text` 即可。
