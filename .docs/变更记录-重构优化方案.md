# 变更记录：重构优化方案落地

日期：2026-08-13

## 背景

审核匹配管线、127 条规则、Agent 执行链与测试工程后，分四阶段落地：先修错误命令与整句漏配，再改造打分/同义词，再补运维缺口与安全，最后工程护栏。

## 功能变更

### 阶段 A — 正确性

- `extract.py`：路径不再吞 CJK；owner 与 mode 分离；`file_keyword` 去「的文件」；URL 不当地径；中英邻接用显式边界；`ping一下` / `打印PATH` 可抽参。
- `docker.ps` 补 `docker ps` / `-a` 与 `risk_level`。
- `perm.chown` 去掉裸词「属主」「归属」，避免抢 `perm.owner.view`。
- `fill_template` 单遍替换；path/text/host 等抽出值做单引号转义；**未抽出的 `{path}` 也保留引号**（`dirname '{path}'`），避免 Java 启停脚本嵌套 `$(dirname {path})` 无法执行。
- `java.app.scripts`：`dirname --` / `basename --`；第三步不依赖上一步的 `$DIR`（每步是独立 shell）。
- 语料回归改用生产阈值（`T_WEAK=4`），环境变量隔离；全量门槛改为 accuracy@10 ≥ 95%。

### 阶段 B — 命中率

- 预处理 `NFKC`。
- 匹配：最长关键词去重 + 字符 2-gram + jieba token 覆盖；完整命中即可入围（短词不再被绝对阈值淘汰）；完整命中优先于纯 ngram。
- `resources/dict/synonyms.json` 查询侧同义扩展；`negation.json` 否定语气降权并在详情打标。
- jieba `add_word` 注入规则词；停用词对规则词表求差。
- 基准脚本：`scripts/bench_corpus.py` → `.docs/命中率对照-重构后.md`。

### 阶段 C — 缺口与安全

- 新增意图：git / tar / curl / traceroute / 已建立连接 / 用户 / sudo / swap / SELinux / 复制移动 / k8s svc·desc。
- `system_adapt.json`：fedora(dnf)、arch、suse、alpine；RHEL 8+ 走 dnf。
- loader 校验 risk_level；`/reload` 失败保留旧规则。
- 高危识别覆盖 `rm --recursive --force`、`find -delete`、`wipefs`、`mkfs.*`。
- 抽出值含 `;|&$` 时风险升为 high。

### 阶段 D — 工程

- `.gitignore`：`data/`、`/lch.spec`。
- 删除根目录误提交的 PyInstaller `lch.spec`。
- `scripts/lib/python_pick.sh` 统一解释器探测（去掉硬编码 miniconda）。
