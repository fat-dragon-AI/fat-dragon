## 现象

`./scripts/build_release.sh` 报大量 `rm: 权限不够`（`build/pyi`、`dist/lch`）。

## 原因

Docker QEMU arm64 构建以 **root** 写入挂载的 `build/`、`dist/lch`；其后普通用户无法清理。路径中可见 `aarch64-linux-gnu` 即为残留。

## 处理

1. 一次性：`sudo chown -R "$USER:$USER" build dist`  
2. 脚本：工作目录改为 `build/pyi-<x64|arm64>`；清理失败时打印 chown 提示  
3. 说明写入 `scripts/README.md`
