## 功能变更

1. **`requirements-build.txt`**  
   - 补充清华源优先 / PyPI 兜底的安装命令  
   - 补充各包国内与官方 simple 索引地址  
   - 指向 `./scripts/install_build_deps.sh`

2. **新增 `scripts/install_build_deps.sh`**  
   - 与 `bin/lch` 相同的解释器选择（`LCH_PYTHON` → `.venv` → miniconda → PATH）  
   - `python -m pip install -r requirements-build.txt` + 国内镜像 + 国外兜底  
   - 装完校验 `PyInstaller` / `jieba`

3. **`build_release.sh`**  
   - 不再裸调 PATH 的 `python3`（本机常落到 `/usr/bin/python3`，无 pip、无 PyInstaller）  
   - 使用同一套 `pick_python`，与开发入口一致

## 安装（需确认后执行）

> 本次下载优先使用国内镜像源，若连接超时/资源不存在会自动切换国外官方源，需要你确认后再执行。

```bash
./scripts/install_build_deps.sh
# 等价：
# $PY -m pip install -r requirements-build.txt \
#   -i https://pypi.tuna.tsinghua.edu.cn/simple \
#   --extra-index-url https://pypi.org/simple
```

## 本机现状（2026-08-11）

- PATH `python3` → `/usr/bin/python3`（无 pip）  
- 实际可用：`~/.local/miniconda3/bin/python3`（已有 jieba / PyInstaller 6.22 / hooks）  
- 构建请直接 `./scripts/build_release.sh`（会选到 conda）
