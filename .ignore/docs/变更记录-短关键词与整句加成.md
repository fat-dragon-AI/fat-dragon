## 问题

输入 `path` / `java` 等短词未命中（规则只有较长口语关键词）。

## 改动

1. **规则**：约 69 条补全常用短词/命令名（如 `path`→查看 PATH，`java`/`jdk`→版本，`docker`→容器列表，`nginx`/`mysql`/`redis` 等）。
2. **匹配**：整句等于某关键词时 **+8** 分，短查询更稳。
3. **防误伤**：长度 ≤4 的纯 ASCII 关键词按词边界匹配（避免 `java`∈`javascript`、`os`∈`process`）。
4. **过宽词**：去掉单独的「系统/配置/服务/安装/日志…」等易大面积误伤的词；裸 `nginx` 归配置查看。
