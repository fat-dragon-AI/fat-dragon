## 功能变更

- 新增入口：`lch -agent` / `lch --agent`
- 交互形态：纯终端 REPL（`lch>` 意图 / `agent>` 命令框）
- 执行方式：
  - 选候选编号
  - 或手动输入完整命令（方便替换端口等参数）
- 安全：任意执行前二次确认（low/medium 用 `y`；high/critical 用 `YES`）
- 默认 `lch` 仍只读不执行；禁止匹配后静默自动执行
- 新增可选审计文件 `data/agent_audit.jsonl`

## 未改动

- 主包 / 规则 / soft_res 三分离
- soft_res 仍以路径索引为主；Agent 下安装语句须逐步确认
- 匹配算法与规则 schema 主体不变
