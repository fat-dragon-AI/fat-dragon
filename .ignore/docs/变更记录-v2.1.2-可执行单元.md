## 功能变更

- 引入可执行单元 `candidates[]`，`kind` 三种：
  - **single**：单条命令
  - **sequence**：多条命令按顺序执行（一次确认；默认失败即停）
  - **script**：指定脚本路径（+ 可选解释器与参数）
- `cmd_template` 保留为多个 single 的简写兼容
- Agent 选主编号 = 执行整个 Runnable；需逐步确认时拆成多个 single
- 手输支持：单行（single）、多行（sequence）、`script:/path`（script）
- 确认预览与审计增加 `kind` / steps / script_path
- 新增执行引擎模块职责说明

## 未改动

- 默认只读、二次确认、持续会话至 `/quit` 或 Ctrl+C
- 主包 / 规则 / soft_res 三分离
