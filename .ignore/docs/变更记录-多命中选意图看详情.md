## 行为

| 命中数 | 表现 |
|--------|------|
| 0 | 未匹配提示 |
| 1 | 直接展示命令详情 |
| ≥2 | **先简要列表**（描述 / intent_id / 置信 / 风险 / 命令条数），`选>` 编号后看详情 |

## Agent

1. 多命中 → `选>` 选意图 → 详情 → `agent>` 选命令执行  
2. `agent>` 输入 `i` 可回到意图列表再选  
3. 再输中文仍走列表选择流程  

## 查询模式

- 交互：可反复 `选>` 查看不同意图，空行返回 `lch>`  
- 非 TTY：打印列表 + 默认第 1 条详情
