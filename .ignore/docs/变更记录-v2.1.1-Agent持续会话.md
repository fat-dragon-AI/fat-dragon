## 功能澄清 / 变更

- 明确 `lch -agent` 为**持续会话**：同一进程内可反复「询问 → 确认执行 → 再询问」
- 会话结束条件仅：`/quit`、`/exit`、`quit`、`exit` 或 **Ctrl+C**
- `agent>` 下空行 / `n` 只跳过本轮候选，**不结束会话**，回到 `lch>` 继续下一轮
- 取消用单独 `q` 表示跳过，避免与退出语义混淆
- 验收补充：同一会话连续 ≥2 轮询问+执行；Ctrl+C 优雅退出并回收子进程
